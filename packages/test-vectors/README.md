# @laya/test-vectors — generated, never hand-edit

Single source of truth for fixtures and reports consumed by the Python
pipeline (`tools/export/`), the TS runtime checks (`packages/laya-js`), and
the playground (`apps/playground`). Every file here is produced by a script;
to regenerate, run the listed command with the pinned checkpoint offline.

## vectors/ (inputs + expected outputs)

| file | generated by |
|---|---|
| `orig-3q.json`, `choice-3.json`, `choice-2.json`, `choice-6.json`, `mixed-batch.json` | `.venv/bin/python tools/export/emit_js_fixtures.py` (from `parity-report.json` + `vectors/*.npz`) |
| `*.npz` (same 5 names) | `.venv/bin/python tools/export/check_parity.py` (torch vs ORT raw outputs) |
| `bpe-fuzz.json` | `.venv/bin/python tools/export/emit_bpe_fuzz.py` (206 tokenizer cases) |
| `act_head.json` + `act_head.meta.json` + `act_head.bin` | `.venv/bin/python tools/export/emit_act_bin.py` (reads `tools/export/act_head.npz`; `.bin` is the fast Float32 path, `.json` the fallback) |

## reports/ (verdicts, asserted by `tools/export/tests/test_reports.py`)

| file | generated by |
|---|---|
| `parity-report.json` | `check_parity.py` (exits 1 on drift; CI-gatable) |
| `fp16-parity.json` | `check_fp16.py` |
| `accuracy-report.json` | `check_accuracy.py` (13 weak checks) |
| `laya-faithful-metadata.json` | `export_onnx.py` (opset, revisions, operator histogram) |

## Rules

- Do not edit by hand; do not commit files >5MB here (large artifacts live
  gitignored in `/models/` and are referenced, not stored).
- Reports must contain no absolute paths (`test_metadata_pins` asserts this).
